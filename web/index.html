User Manual

  • SLOTS: Manage two Memory Units simultaneously using the Slot A and Slot B tabs in the sidebar.
  • LOAD: Drag an Xbox Memory Unit image (.bin/.img) onto the dashboard for the active slot, or directly onto a Slot Tab to load it there.
  • TRANSFER: Move or copy saves between slots by selecting a save and choosing the Transfer option from the action menu.
  • EXPORT: Use the Export button in the sidebar to save your modified card image or export all saves to a ZIP.
  • IMPORT: Drag a save ZIP onto the dashboard for the active slot, or onto a Slot Tab to inject it into that specific card.
  • DELETE: Use the Delete button on the save detail view to remove content from the active card.
