User Manual

  • LOAD: Drag and drop an Xbox Memory Unit (.bin/.img) image file or a save (.zip) onto the dashboard to begin.
  • VIEW: Use the sidebar tree to navigate between games and individual saves.
  • EXPORT: Select a save to export it to your computer as a ZIP, or use the "Export Card" button in the header to save the modified image.
  • IMPORT: Drag any save ZIP directly onto the dashboard to inject it into the currently loaded card image.
  • DELETE: Use the trash icon on the save detail view to remove content from the image.
